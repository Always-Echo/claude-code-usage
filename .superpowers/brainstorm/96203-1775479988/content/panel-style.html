点击图标后的展示形式

点击菜单栏图标后，如何展示用量数据？

A

原生下拉菜单

macOS 标准菜单样式，每行显示一条数据（今日花费 $0.42、本周 $2.1…）。轻量，系统风格一致。

优点

  • 开发最简单
  • 原生系统风格

缺点

  • 排版能力弱，无法做卡片/图表
  • 不支持自定义配色
B

自定义弹出面板（推荐）

点击后弹出一个自定义 NSPopover 窗口，可完全自定义 UI，使用 Supabase 配色做卡片式布局，支持 Tab 切换日/周/月/年。

优点

  • UI 完全可控，可实现设计稿效果
  • 支持卡片、分组、颜色高亮
  • Tab 切换维度体验好

缺点

  • 开发量稍大
