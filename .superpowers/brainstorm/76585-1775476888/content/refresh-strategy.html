数据刷新策略

菜单栏 app 如何获取最新的 token 用量数据？

A

点击时实时读取

每次点击菜单栏图标时，实时扫描本地 JSONL 文件并计算。数据始终最新，无后台进程。

优点

  • 数据实时准确
  • 无后台常驻进程

缺点

  • 点击后有短暂延迟
  • 文件多时稍慢
B

定时自动刷新

后台每隔 N 分钟（如 5 分钟）自动重新读取文件，菜单栏图标可显示今日用量摘要。

优点

  • 打开即看到数据，无等待
  • 可在图标上显示实时摘要

缺点

  • 有后台常驻进程
  • 数据可能有几分钟延迟
C

文件监听（推荐）

使用 macOS FSEvents 监听 ~/.claude/projects/ 目录变化，有新数据时自动更新，其他时间不占资源。

优点

  • 近乎实时，有变化才更新
  • 资源占用极低
  • 可在图标上显示实时摘要

缺点

  • 需要文件系统监听权限
  • 实现稍复杂
